# Three Crises — Crime, Punishment & Homelessness in Hawaiʻi

A static, dependency-free data site bringing three official Hawaiʻi datasets into one frame:
crime, incarceration, and homelessness.

**Live:** https://jungle198935.github.io/three-crises-hawaii/

Built from public data: Hawaiʻi AG/CPJAD Uniform Crime Reports (1975–2021), HUD Point-in-Time
counts (2007–2025), DBEDT State of Hawaiʻi Data Book 2025 (Tables 4.20, 4.22), BJS *Prisoners in
2023*, and 2020 Census. Reporting mechanisms are attributed to Honolulu Civil Beat and labelled
as secondary reporting.

No trackers, no analytics, no external requests. Open `index.html` directly to run it offline.
